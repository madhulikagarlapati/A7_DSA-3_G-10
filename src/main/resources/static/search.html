Search Algorithms

TEXTFORGE currently provides four classic string-searching algorithms.

Naive Search

Checks possible starting positions one by one.

KMP

Uses the Longest Prefix Suffix table to avoid unnecessary comparisons.

Z Algorithm

Uses Z-values to identify pattern matches efficiently.

Rabin-Karp

Uses rolling hash values to locate patterns.
