Project Overview

The main scheduling problem is based on dependencies, task priority and processor availability.

  • Tasks can have different priorities.
  • Tasks can depend on other tasks.
  • Multiple processors can execute independent tasks in parallel.
  • Dependencies must be completed before dependent tasks can start.
  • The scheduler produces processor assignments and an execution timeline.
